IDLM: Inverse-distilled Diffusion Language Models

Diffusion language models can generate text by gradually denoising tokens, but their many-step sampling procedure is slow. IDLM asks a different distillation question: what fast student distribution would make the pretrained teacher the optimal denoiser?

Project Page Paper Code

1. Motivation

Why Distill Diffusion Language Models?

Diffusion Language Models are attractive because they generate text through iterative refinement rather than left-to-right autoregression. This gives them a different modeling geometry and makes them promising for controllable and parallel text generation. The cost is inference: strong teachers often use hundreds or thousands of reverse denoising steps.

Existing distillation methods often teach a student to skip along teacher trajectories. That can be cheap, but in the few-step regime a single transition must replace many small teacher updates. IDLM follows a distribution-matching view instead. The goal is not only to mimic the next teacher move, but to train a student whose generated distribution remains consistent with the pretrained teacher.

Core question. If the teacher \(f^\star\) is fixed, what distribution \(p_\theta\) should the student generate so that the teacher remains the best denoiser?

2. Method

Teacher-vs-Fake Distribution Matching

IDLM starts from the inverse-distillation objective. Let \(f^\star\) be the frozen teacher trained on real data, and let \(p_\theta\) be the distribution produced by the student. IDLM compares the teacher loss on student samples with the loss of a fake diffusion model trained on the current student distribution:

\[ \mathcal{L}_{\mathrm{IDLM}}(\theta) = \mathcal{L}(f^\star, p_\theta) - \min_f \mathcal{L}(f, p_\theta) \]

The fake model is important. It represents what the current student can already explain by itself. The teacher provides attraction toward data-like samples; the fake model provides a repulsive signal against samples that are only supported by the student's own artifacts.

Path Matching, Not Just Marginal Matching

The theory shows that the ideal IDLM loss matches full diffusion paths, \(\mathrm{KL}(P_\theta \,\Vert\, P^\star)\). DMD-like methods instead match noised marginals at sampled times. A stop-gradient reduction can make inverse distillation look DMD-like, but that changes the full gradient.

Discrete Tokens Need Process-Aware Gradients

For masked diffusion, the \(\mathrm{SUBS}\) parameterization copies revealed tokens, so non-mask branches cancel and only masked positions carry signal. For uniform diffusion, tokens can be revised repeatedly, so the Duo relaxation keeps gradients through intermediate states.

Few-step, Not One-step

One-step text generation is unstable for masked diffusion because the terminal state is fully masked and too deterministic. IDLM therefore targets practical few-step generation, where the student can reuse the teacher-style sampling procedure with far fewer steps.

3. Results

Fewer Reverse Steps, Similar Teacher Quality

IDLM is evaluated on conditional math generation and unconditional text generation. The main message is consistent across settings: the student recovers teacher-level quality with many fewer reverse steps, while diversity metrics help check that lower perplexity is not simply mode collapse.

3.1 GSM8K

The conditional generation experiment follows the TinyGSM/GSM8K protocol. The prompt is clamped and the model generates the solution region. IDLM preserves diffusion-teacher accuracy with fewer sampling steps, although autoregressive baselines remain much stronger on this reasoning benchmark.

4. Conclusion

What IDLM Teaches Us

IDLM shows that diffusion language model distillation can be framed as a distribution-matching problem: train a fast student \(p_\theta\) whose samples are supported by the teacher \(f^\star\) more than by a fake model trained on the student's current distribution. This viewpoint gives a clean theoretical target and a practical few-step training recipe.

The most useful intuition is teacher-vs-fake contrast. For masked diffusion, this contrast becomes a clean mask-only update because \(\mathrm{SUBS}\) copies revealed tokens. For uniform diffusion, the same idea teaches both which token to choose and when to jump between intermediate states. Across the reported experiments, this produces substantial sampling acceleration while preserving the teacher's generation quality and diversity.
