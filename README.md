# David Li Research Homepage

This is a small Django research homepage with two visual layouts:

- Classic layout: `/`
- Experimental concept layout: `/concept/`

Most page content lives in `homepage/profile_data.py`. The HTML templates are in
`homepage/templates/homepage/`, and the CSS files are in `homepage/static/homepage/`.

## Local Development

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py runserver 127.0.0.1:8000
```

Open:

- `http://localhost:8000/`
- `http://localhost:8000/concept/`

## Important Clickable Areas

Classic layout:

- Hero buttons: Email, Google Scholar, LinkedIn, X
- Selected work cards
- Paper and code links
- Footer contact icons

Concept layout:

- `Classic layout` link in the left panel
- Left rail links: Email, Scholar, LinkedIn, X
- Top navigation: Direction, Work, Papers, Contact
- Selected work cards
- Paper and code links
- Final email contact button

## Publishing On Render

This repository is prepared for Render using `render.yaml`.

1. Create a GitHub repository.
2. Push this project to GitHub.
3. In Render, choose **New +** then **Blueprint**.
4. Connect the GitHub repository.
5. Render will read `render.yaml`.
6. Deploy the service.
7. Open the generated Render URL.

The important production settings are already prepared:

- `DJANGO_DEBUG=False`
- `DJANGO_SECRET_KEY` generated by Render
- `DJANGO_ALLOWED_HOSTS=.onrender.com`
- `DJANGO_CSRF_TRUSTED_ORIGINS=https://*.onrender.com`
- `gunicorn` for serving Django
- `whitenoise` for static files

For a custom domain, add the domain in Render and update `DJANGO_ALLOWED_HOSTS`
to include it, for example:

```text
.onrender.com,yourdomain.com,www.yourdomain.com
```

Also add matching CSRF origins:

```text
https://*.onrender.com,https://yourdomain.com,https://www.yourdomain.com
```
